# 🎮 CYBER TETRIS (웹 버전)

브라우저에서 바로 실행되는 사이버펑크 테트리스입니다. 설치 없이 `index.html` 하나로 동작합니다.

## GitHub Pages 배포
1. 저장소에 `index.html`을 올립니다.
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. `https://<아이디>.github.io/<저장소명>/` 접속

## 조작법
← → 이동 · ↑ 회전 · ↓ 소프트 드롭 · SPACE 즉시 낙하 · P 일시정지 · M 음악 · R 재시작
(모바일은 화면 아래 버튼 사용)
